オンライン書店

オンライン書店のカタログ管理と購入フローを定義するALPSプロファイル。RESTful APIとUIの両方に対応するセマンティック定義を提供します。

goToCart
doUserInfo
doShippingInfo		 tag:checkoutdoc:購入手続き画面。顧客情報、配送先の入力を行い、支払いに進む。注文確定前の最終確認を表示。
doAddToCart カートに追加 id
quantity		 tag:cartrel:collectionrt:#ShoppingCartdoc:指定した書籍をショッピングカートに追加。既にカート内にある場合は数量を増加。在庫を超える注文はエラー。
doPaymentInfo 支払い情報入力 paymentMethod tag:paymentrt:#Paymentdoc:注文の支払い方法を選択し、必要な決済情報を入力。クレジットカード選択時はカード情報を入力しバリデーション。
doPlaceOrder 注文確定 tag:orderrt:#Paymentdoc:入力情報に基づき注文を確定し、決済処理を行い、支払い画面に注文確認情報を表示。決済実行、在庫確保、確認メール送信を行う。この操作は取り消し不可。
doRemoveFromCart カートから削除 id tag:cartrt:#ShoppingCartdoc:指定した商品をカートから完全に削除。カート内に存在しない場合は変更なし。
doShippingInfo 配送情報入力 shippingAddress tag:shippingrt:#Checkoutdoc:商品の配送先住所を入力。郵便番号による住所自動入力機能あり。
doUpdateQuantity カート内数量変更 id
quantity		 tag:cartrt:#ShoppingCartdoc:カート内の特定商品の数量を変更。0以下の値は指定不可。在庫を超える数量はエラー。
doUserInfo 顧客情報入力 userName
userEmail		 tag:customerrt:#Checkoutdoc:顧客の氏名とメールアドレスを入力。メールアドレスは正規表現でバリデーション。
goGetCategories カテゴリ一覧取得 tag:catalogrel:collectionrt:#Catalogdoc:利用可能な全書籍カテゴリの一覧を取得。階層カテゴリの場合は親子関係も返却。
goListBooks 書籍一覧取得 tag:catalogrel:collectionrt:#Catalogdoc:カタログ内の全書籍の一覧を取得。ページネーション（デフォルト20件/ページ）と並び順（新着順、価格順、人気順など）の指定が可能。
goListCartItems カート内商品一覧取得 tag:cartrel:collectionrt:#ShoppingCartdoc:現在のショッピングカート内の全商品を取得。数量、小計、合計金額を含む。
goOrderDetails 注文詳細表示 tag:orderrt:#Paymentdoc:確定した注文の詳細情報を支払い画面に表示。注文番号、購入商品一覧、合計金額、配送先、支払い方法などを含む。
goSearchBooks 書籍検索 query tag:catalogrel:collectionrt:#Catalogdoc:指定した検索キーワードに基づいて書籍を検索。タイトル、著者名、内容説明、ISBNなど複数フィールドを横断検索可能。
goToBookDetails 書籍詳細画面へ id rt:#Bookdoc:選択した書籍の詳細情報画面に遷移。書籍IDの指定が必要。
goToCart カート画面へ rt:#ShoppingCartdoc:現在のショッピングカートの内容を表示する画面に遷移。
goToCatalog カタログ画面へ rt:#Catalogdoc:書籍カタログ一覧画面に遷移。全書籍が表示される。
goToCategory カテゴリ画面へ id tag:catalogrt:#Categorydoc:選択したカテゴリで絞り込まれた書籍を表示するカテゴリ詳細画面に遷移。
goToCheckout 購入手続き画面へ rt:#Checkoutdoc:カート内容を確認し購入手続きに進む画面に遷移。カートが空の場合は遷移不可。
goToHome ホーム画面へ rt:#Homedoc:アプリケーションのホーム画面に遷移。どの画面からもアクセス可能。
goToPayment 支払い画面へ rt:#Paymentdoc:支払い情報を入力し注文を確定する画面に遷移。
Home ホーム画面 goToCatalog
goToCart		 def:schema.org/WebPagetag:navigationdoc:アプリケーションの起点。サイト全体のナビゲーションとプロモーション情報を表示。
id 識別子 def:schema.org/identifiertag:coredoc:各リソースの一意な識別子。UUIDまたは自動生成の整数。
isbn ISBN def:schema.org/isbntag:catalogdoc:国際標準図書番号。ISBN-13形式、ハイフン区切り。
Payment 支払い画面 paymentMethod
goOrderDetails
goToHome
goToCart
doPaymentInfo
doPlaceOrder		 tag:paymentdoc:支払い情報の入力、注文の確定、注文完了情報の表示を行う画面。支払い方法の選択、決済処理、注文確定を処理し、完了時に注文番号、合計金額、配達予定日を表示。確認メールは自動送信。
paymentMethod 支払い方法 def:schema.org/paymentMethodtag:paymentdoc:注文の支払い方法。クレジットカード、代金引換、銀行振込など。
price 価格 def:schema.org/pricetag:commercedoc:書籍の販売価格。税抜き金額（日本円）。
quantity 数量 def:schema.org/quantityValuetag:commercedoc:カート内の書籍数量。1以上の整数値。
query 検索キーワード tag:catalogdoc:書籍検索に使用するキーワードまたは条件。タイトル、著者名、ISBNなどで検索可能。
shippingAddress 配送先住所 def:schema.org/addresstag:shippingdoc:商品の配送先住所。郵便番号、都道府県、市区町村、番地、建物名を含む。
ShoppingCart ショッピングカート totalAmount
goListCartItems
goToCheckout
goToCatalog
doUpdateQuantity
doRemoveFromCart		 def:schema.org/ShoppingCarttag:cartdoc:購入予定の書籍を入れるカート。数量変更、削除、合計金額確認が可能。セッション単位で管理。
title タイトル def:schema.org/nametag:catalogdoc:書籍のタイトルまたはカテゴリ名。最大200文字の文字列。
totalAmount 合計金額 def:schema.org/totalPricetag:commercedoc:注文またはカート内容の合計金額。税込み表示。
userEmail メールアドレス def:schema.org/emailtag:customerdoc:顧客の連絡先メールアドレス。注文確認メールの送信に使用。
userName 顧客名 def:schema.org/nametag:customerdoc:顧客の氏名。姓と名をスペースで区切り。
